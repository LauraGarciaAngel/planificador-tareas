# Planificador de Tareas

Aplicación web para gestionar tareas. Proyecto del Sprint 1 del bootcamp de desarrollo web.

## Descripción
- **Tarea 1:** estructura con HTML5 y Bootstrap 5 (encabezado, formulario y lista).
- **Tarea 2:** lista de tareas con tarjetas (Cards) estáticas de ejemplo.
- **Tarea 3:** validación del formulario con JavaScript y alertas de Bootstrap.

## Tecnologías
HTML5, CSS3, Bootstrap 5 (CDN) y JavaScript Vanilla.
